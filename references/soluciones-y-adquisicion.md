# Soluciones y adquisición

Síntesis independiente basada en el material formativo acreditado en el README. Las referencias internas y marcas de tiempo de las clases privadas se omiten deliberadamente.

## Catálogo de hipótesis

El material enumera automatizaciones frecuentes. Usalas para generar hipótesis después de entender el problema:

| Situación | Solución posible | Resultado a investigar |
| --- | --- | --- |
| Consultas sin respuesta rápida | Respuesta inicial y clasificación | Menos oportunidades enfriadas |
| Prospectos sin continuidad | Seguimiento automático | Más conversaciones retomadas |
| Coordinación manual | Agendamiento | Menos intercambio operativo |
| Ausencias a citas | Recordatorios | Menos huecos y tiempo perdido |
| Altas desordenadas | Onboarding | Menos tareas manuales y mejor continuidad |
| Información dispersa | Reportes automáticos | Menos tiempo de consolidación |
| Carritos abandonados | Recuperación de carrito | Ventas potencialmente recuperadas |
| Contactos inactivos | Reactivación | Nuevas conversaciones desde una base existente |
| Consultas repetitivas | Respuestas automatizadas | Equipo liberado para tareas de mayor valor |
| Posventa irregular | Seguimiento, estado y reseñas | Mejor experiencia y recompra potencial |

No traslades porcentajes, estudios o resultados mencionados verbalmente sin verificar fuente, vigencia y aplicabilidad. La reactivación de contactos y los mensajes automáticos dependen del consentimiento, la privacidad y las reglas del canal.

## Demo funcional

La demo sirve para volver visible una solución. El recorrido sugerido es:

1. definir un problema específico;
2. construir un MVP que muestre el flujo principal;
3. explicar primero el resultado;
4. mostrar después las funciones necesarias;
5. hacer una propuesta concreta o acordar el siguiente paso.

Una demo demuestra funcionamiento, no ROI ni demanda. Evitá presentarla como caso real si utiliza datos hipotéticos.

## Secuencia de adquisición extraída

El material propone avanzar por etapas:

### 1. Red y conversaciones

- empezar con contactos existentes;
- pedir presentaciones o referidos;
- hablar con negocios del segmento;
- aprender cómo describen sus problemas.

### 2. Oferta directa con demo

- elegir un problema y un segmento;
- preparar un MVP funcional;
- presentar beneficio, funcionamiento y oferta.

### 3. Documentación y contenido

- registrar proyectos, procesos, resultados y detrás de escena;
- explicar decisiones y diferencias de implementación;
- crear contenido para problemas específicos;
- evitar inventar experiencia o resultados.

### 4. Escala paga

El material ubica los anuncios después de tener una oferta probada, conversaciones, casos y contenido suficiente.

## Límites de uso

Las transcripciones recomiendan tácticas intensivas de contacto presencial y seguimiento. Los documentos de análisis advierten que no deben convertirse en insistencia indefinida, contacto fuera de contexto, grabación sin permiso o mensajería masiva sin consentimiento. Tratá la elección del canal y la frecuencia como decisiones contextuales.
